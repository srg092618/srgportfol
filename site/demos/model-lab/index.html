Gradient descent: how a model learns

Loss surface
0.020
Step 0

Click anywhere on the surface to drop a new starting point.

How it works

Training a model means searching for the parameters that make its error smallest. Gradient descent does this by repeatedly updating the parameters in the direction of the negative gradient, −∇L(θ).

Plain SGD applies the raw gradient step. Momentum accumulates an exponentially weighted velocity, which speeds progress along low-curvature directions such as the curved ravine of the Rosenbrock function. Adam adapts the step size per parameter using estimates of the first and second moments of the gradient.

Select the ill-conditioned quadratic (condition number κ = 25) and raise η to watch SGD oscillate across the high-curvature axis. Past η = 2/λmax = 0.08, SGD diverges.

Mathematical representation

// SGD θ ← θ − η ∇L(θ) // Momentum (β = 0.9) v ← βv + ∇L(θ); θ ← θ − η v // Adam (β₁ = 0.9, β₂ = 0.999, ε = 1e-8) m ← β₁m + (1 − β₁)∇L; v ← β₂v + (1 − β₂)(∇L)² m̂ = m / (1 − β₁ᵗ); v̂ = v / (1 − β₂ᵗ) θ ← θ − η · m̂ / (√v̂ + ε) // Test functions Rosenbrock: f = (1 − x)² + 4(y − x²)² Quadratic: f = ½(x² + 25y²) Double well: f = (x² − 1)² + 2y² + 0.3x

How it works

Linear regression has an exact answer: ordinary least squares solves for the best slope and intercept in closed form. Gradient descent reaches the same line iteratively, which is how far larger models are trained when no closed form exists.

The dashed line is the OLS solution. The solid line is gradient descent, starting from zero. Click the plot to add points and watch both answers move. The thin vertical lines are residuals, the errors the model is trying to shrink.

Mathematical representation

ŷ = w·x + b MSE(w, b) = (1/n) Σ (yᵢ − ŷᵢ)² ∂MSE/∂w = −(2/n) Σ xᵢ (yᵢ − ŷᵢ) ∂MSE/∂b = −(2/n) Σ (yᵢ − ŷᵢ) // closed form (OLS) w = Σ (xᵢ − x̄)(yᵢ − ȳ) / Σ (xᵢ − x̄)² b = ȳ − w·x̄

Model lab · Model selection

Underfitting, overfitting and the point between

3
Fit

How it works

A model with too few degrees of freedom misses the pattern. One with too many memorizes the noise in its training set and fails on new data. This is the bias–variance trade-off, and choosing where to sit on it is most of practical modeling.

Here a polynomial is fit to 16 noisy samples of a sine wave. Raise the degree and training error keeps falling, while error on 300 held-out points falls, then climbs. The best model is the one at the bottom of the test curve.

Mathematical representation

y = sin(πx) + ε, ε ~ Normal(0, 0.3²) ŷ(x) = Σₖ βₖ Pₖ(x), k = 0 … d β = (ΦᵀΦ + λI)⁻¹ Φᵀy // λ = 1e-6 // Pₖ: Legendre polynomials on [−1, 1] E[(y − ŷ)²] = bias² + variance + σ²

How it works

The central limit theorem says the mean of n independent draws is approximately normal, whatever shape the original data has (as long as its variance is finite), with spread σ/√n. It is why confidence intervals, A/B tests and most of classical inference work.

Pick a skewed or bimodal source distribution, then raise n. The histogram of 2,000 sample means tightens and settles onto the predicted normal curve.

Mathematical representation

X̄ₙ = (1/n) Σ Xᵢ X̄ₙ ≈ Normal(μ, σ² / n) // as n grows SE = σ / √n // 95% confidence interval for the mean x̄ ± 1.96 · s / √n

Where it is used

Retail

A/B tests on price and promotion

The standard error tells you whether a lift in sales is real or within normal week-to-week variation.

 Finance

Audit sampling

An error rate across thousands of transactions is estimated from a sample, with a stated margin.

 Manufacturing

Quality control charts

Batch averages are tracked against control limits to catch a process that is drifting.

 Healthcare

Patient surveys

Satisfaction scores are reported with a margin of error so small changes are not over-read.

How it works

Each customer is a point in six dimensions, one per measurement. Nobody can look at six dimensions, so the plot shows the three directions that carry the most variation, found by principal component analysis. The clustering itself runs on all six.

k-means places k centroids, assigns every point to its nearest centroid, moves each centroid to the mean of its points, and repeats until no point changes cluster. Measurements are standardized first so that no single one dominates the distances.

Try k = 2 and k = 4. The elbow chart shows how much each extra cluster reduces the objective, and the profile chart shows what makes each cluster different.

Mathematical representation

// objective: within-cluster sum of squares J = Σᵢ ‖xᵢ − μ_c(i)‖² // assignment step c(i) = argminⱼ ‖xᵢ − μⱼ‖² // update step μⱼ = (1/|Cⱼ|) Σ_{i ∈ Cⱼ} xᵢ // PCA projection used for the plot Σ = XᵀX / (n − 1), Σ vₘ = λₘ vₘ zᵢ = [v₁ v₂ v₃]ᵀ xᵢ variance shown = (λ₁ + λ₂ + λ₃) / Σₘ λₘ

How it works

The model splits a sales history into three parts: a level (where sales are now), a trend (how fast they are growing) and a seasonal pattern (the shape of a typical year). Each new month updates all three. This is Holt-Winters exponential smoothing.

α, β and γ set how quickly each part reacts to new data. High values chase recent months, low values stay steady. Optimize picks the values that minimize one-step-ahead squared error on the history.

The last 12 months are hidden from the model, so you can compare the forecast with what happened. The shaded interval widens with the horizon because errors compound. Example data: five years of synthetic monthly sales.

Mathematical representation

// additive Holt-Winters, season length m = 12 ℓₜ = α(yₜ − sₜ₋ₘ) + (1 − α)(ℓₜ₋₁ + bₜ₋₁) bₜ = β(ℓₜ − ℓₜ₋₁) + (1 − β)bₜ₋₁ sₜ = γ(yₜ − ℓₜ₋₁ − bₜ₋₁) + (1 − γ)sₜ₋ₘ // h-step forecast, k = ⌊(h − 1)/m⌋ ŷₜ₊ₕ = ℓₜ + h·bₜ + sₜ₊ₕ₋ₘ₍ₖ₊₁₎ // 95% interval, with β′ = αβ ŷₜ₊ₕ ± 1.96 σₕ, σ² = (1/n) Σ eₜ² // one-step errors σₕ² = σ²[1 + (h − 1)(α² + αβ′h + β′²h(2h − 1)/6) + γk(2α + γ + β′m(k + 1))]
